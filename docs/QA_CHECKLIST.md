# QA Checklist

ตรวจด้วยตาก่อนปิดงานแต่ละขั้น ใช้คู่กับ widget test ที่ตรวจล้นจอ ([ตัดสินใจ: วิธีตรวจเกณฑ์ไม่ล้นจอ 360px และไม่มีเส้นคั่น](https://github.com/symphonicz/snow_flow/issues/37))

1. เปิดทุกหน้าที่ความกว้าง 360px ทั้งภาษาไทยและอังกฤษ ไม่มีข้อความถูกตัดด้วย "…" จนอ่านไม่รู้เรื่อง (ยกเว้นโน้ต)
2. ไม่มีเส้นคั่นหรือเส้นขอบนอกจากเส้นฐานกราฟ (รวมตอน focus ช่องกรอก)
3. ธีมมืด: สีอ่านออก เงาไม่หายจนแยกส่วนไม่ออก
4. ตั้งขนาดตัวอักษรของเครื่องให้ใหญ่ (~1.3) แล้วดูหน้าหลัก
